# 受保护的核心预期

适用本目录及 `history/` 中全部文档、示例、表格和机器可读清单。

修改前阅读 [README.md](README.md) 的适用范围、已知差异和审批流程。
任何核心行为改写都需要人工明确批准具体旧/新语义与影响范围。
未经批准，不把过程讨论、controller 现状、失败结果或修复实现同步成规范。
不要通过改分类、优先级、来源清单或示例间接改变适用预期。

批准前将可审阅的差异写在 workspace 任务的 `PROPOSAL_COMMIT.md`，保留本目录原文。
获批后保存批准依据和变更记录，并更新来源校验值；保留首次归档的来源信息。
纯排版或链接修复仅在没有语义变化时可直接维护。
